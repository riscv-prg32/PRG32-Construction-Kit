# Playing with RISC-V examples

These 36 C and RISC-V assembly source files come from
[`riscv-prg32/Playing-with-RISC-V_PRG32_textbook`](https://github.com/riscv-prg32/Playing-with-RISC-V_PRG32_textbook).
They accompany the assembly, graphics, input, C, tile, and complete-game
lessons in *Playing with RISC-V*.

The examples remain visible source material: students can compare them with
the C generated by the Construction Kit. Files under this directory are
provided under their upstream terms; see `LICENSE-CC0.txt` and the source-file
headers. Complete runnable examples are under `complete/`; the other folders
contain focused lesson fragments.

To build a complete example with the current PRG32 toolchain, from a PRG32
firmware checkout run:

```bash
python3 -m prg32 cartridge build path/to/example.c \
  --portable --entry-prefix example --name example --out example.prg32
```
