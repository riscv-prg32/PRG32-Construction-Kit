# Lección 3: dibuja y convierte un sprite

Objetivo: crear un sprite y convertirlo en un array de C.

## 1. Abre Sprite Lab

Abre tu proyecto en el IDE y haz clic en **Sprite Lab** en el menú superior (o en **Sprites**
en los archivos del proyecto). En la página Proyectos, el botón **Sprite Lab** de la tarjeta de
un proyecto hace lo mismo.

## 2. Crea un sprite nuevo

1. Haz clic en **Nuevo**.
2. Llámalo `player`.
3. Usa 16 por 16 píxeles.
4. Elige un color de pintura.
5. Dibuja un personaje sencillo.

## 3. Guarda

Haz clic en **Guardar**. El sprite se guarda con tu proyecto (como JSON en el servidor, o en
este navegador si no tienes cuenta).

## 4. Convierte a C

Haz clic en **Convertir a C**. El panel de C muestra un array RGB565 de `uint16_t`.

## 5. Encuentra el artefacto

Abre **Artefactos**. Descarga el archivo C generado del sprite.
