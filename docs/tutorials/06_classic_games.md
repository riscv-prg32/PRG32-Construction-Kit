# Tutorial 6: Classic Games

Goal: study, play and change complete games built only from blocks.

1. On the dashboard click **Examples** and add a game marked **complete game**.
2. Open its tutorial: [games/README.md](games/README.md) lists Pong, Breakout,
   Space Invaders, Asteroids and Snake.
3. Present it in class: open `/docs/presentations/<game>.html` and use the
   arrow keys (`F` for full screen). Print to PDF for handouts.
4. Follow the steps: each one shows the exact blocks of the game and the C
   they become.
5. Finish with **Download .prg32** and run the cartridge on the PRG32 board,
   in QEMU or in PRG32-QT.
