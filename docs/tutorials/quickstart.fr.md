# Démarrage rapide (Français)

Autres langues : [English](quickstart.en.md) · [Italiano](quickstart.it.md) ·
[Español](quickstart.es.md) · [Deutsch](quickstart.de.md) · [简体中文](quickstart.zh-Hans.md)

1. **Ouvre le kit** dans un navigateur. Choisis ta langue avec le menu en haut
   (English, Italiano, Español, Français, Deutsch, 简体中文).
2. **Pas de compte ?** Appuie sur *Essayer sans compte* : tes jeux restent seulement dans ce
   navigateur.
3. **Nouveau projet.** Choisis comment l'écrire : **Blocs**, **C**, **Assembleur (RISC-V)** ou
   **Python (PRG32 Python)**. Donne-lui un titre et appuie sur *Créer*.
4. **Exécuter** (Maj+F10) compile le jeu et le lance dans le simulateur à droite. Clique sur
   l'écran, puis utilise les flèches (A et B sont Z et X).
5. **Générer** (Ctrl+Maj+G) montre le C et l'assembleur RISC-V que le kit produit, expliqués ligne
   par ligne. Ils sont identiques dans toutes les langues de l'interface (les commentaires du
   code sont en anglais).
6. **Compiler** (Ctrl+Maj+B, compte nécessaire) crée la cartouche `.prg32` à télécharger, pour y
   jouer sur une console PRG32 ou dans PRG32-QT.
7. **Débogage** : ouvre l'onglet *Débogage*, appuie sur un numéro de ligne pour t'y arrêter, puis
   *Ligne suivante*.
8. **Tes données** : le lien en bas de page *Confidentialité et tes données* explique ce que le
   kit garde et pourquoi.

Enseignants : les tutoriels de [docs/tutorials](.) (en anglais) vont plus loin : jeu
d'attrape, sprites, son, publication, débogueur, PRG32 Python.
