# Lektion 3: ein Sprite zeichnen und umwandeln

Ziel: ein Sprite erstellen und in ein C-Array umwandeln.

## 1. Öffne Sprite Lab

Öffne dein Projekt in der IDE und klicke im Menü oben auf **Sprite Lab** (oder in den
Projektdateien auf **Sprites**). Auf der Projektseite macht der Knopf **Sprite Lab** auf der
Karte eines Projekts dasselbe.

## 2. Erstelle ein neues Sprite

1. Klicke auf **Neu**.
2. Nenne es `player`.
3. Nimm 16 mal 16 Pixel.
4. Wähle eine Malfarbe.
5. Zeichne eine einfache Figur.

## 3. Speichern

Klicke auf **Speichern**. Das Sprite wird mit deinem Projekt gespeichert (als JSON auf dem
Server oder, ohne Konto, in diesem Browser).

## 4. In C umwandeln

Klicke auf **In C umwandeln**. Das C-Feld zeigt ein RGB565-Array aus `uint16_t`.

## 5. Finde das Artefakt

Öffne **Artefakte**. Lade die erzeugte C-Datei des Sprites herunter.
