# 快速入门（简体中文）

其他语言：[English](quickstart.en.md) · [Italiano](quickstart.it.md) · [Español](quickstart.es.md) ·
[Français](quickstart.fr.md) · [Deutsch](quickstart.de.md)

1. **在浏览器中打开本工具。** 用页面顶部的菜单选择语言
   （English、Italiano、Español、Français、Deutsch、简体中文）。
2. **没有账户？** 点击“不注册直接试用”：你的游戏只保存在这个浏览器里。
3. **新建项目。** 选择写法：**积木**、**C**、**汇编（RISC-V）** 或
   **Python（PRG32 Python）**。给它起个标题，然后点击“创建”。
4. **运行**（Shift+F10）会构建游戏，并在右边的模拟器中启动它。点击屏幕，
   然后用方向键操作（A 和 B 是 Z 和 X）。
5. **生成**（Ctrl+Shift+G）会显示本工具生成的 C 和 RISC-V 汇编，并逐行解释。
   无论界面用哪种语言，它们都完全一样。
6. **编译**（Ctrl+Shift+B，需要账户）会制作可下载的 `.prg32` 卡带，
   可以在 PRG32 游戏机或 PRG32-QT 上玩。
7. **调试**：打开“调试”标签页，点击一个行号让程序在那里停下，然后点击“下一行”。
8. **你的数据**：页脚的“隐私与你的数据”链接说明本工具保存了什么，以及为什么。

老师们：[docs/tutorials](.) 中的教程讲得更深入（接球游戏、精灵、声音、
发布、调试器、PRG32 Python）。
