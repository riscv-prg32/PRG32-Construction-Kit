# Lezione 3: disegna e converti uno sprite

Obiettivo: creare uno sprite e convertirlo in un array C.

## 1. Apri Sprite Lab

Apri il tuo progetto nell'IDE e fai clic su **Sprite Lab** nel menu in alto (oppure su
**Sprite** nei file del progetto). Nella pagina Progetti, il pulsante **Sprite Lab** della
scheda di un progetto fa la stessa cosa.

## 2. Crea un nuovo sprite

1. Fai clic su **Nuovo**.
2. Chiamalo `player`.
3. Usa 16 per 16 pixel.
4. Scegli un colore del pennello.
5. Disegna un personaggio semplice.

## 3. Salva

Fai clic su **Salva**. Lo sprite viene conservato con il tuo progetto (come JSON sul server,
oppure in questo browser se non hai un account).

## 4. Converti in C

Fai clic su **Converti in C**. Il pannello C mostra un array RGB565 di `uint16_t`.

## 5. Trova l'artefatto

Apri **Artefatti**. Scarica il file C generato dello sprite.
