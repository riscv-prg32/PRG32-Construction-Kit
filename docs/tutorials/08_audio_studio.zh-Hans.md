# 第 8 课：用 AudioStudio 制作音效和音乐

时间：大约 30 分钟。你需要一个积木项目（第 2 课的接东西游戏就很合适）。

## 1. 打开 AudioStudio

打开你的项目，按 **AudioStudio**。**声部** 标签页显示 PRG32 游戏机的 8 个声部。按 **试听**：你会听到
声部 0。把 **起音**（Attack）滑块往右拉，再试一次：现在音符会慢慢变响。看看包络的图形怎么变化。

## 2. 制作一个音效

1. 打开 **音效**，按 **新建**。
2. 把它命名为 `Catch`。
3. 把 **音符** 设为 76，**长度** 设为 120 毫秒。选择声音 **pulse**。
4. 把 **延音**（Sustain）设为 0，**衰减**（Decay）设为 60：一个短短的“哔”声。按 **试听**。

## 3. 写一段小旋律

1. 打开 **配乐**，按 **新建**。把它命名为 `Theme`。
2. 点击声部 0 的第一步，输入 `C4`。按右方向键，输入 `E4`，然后 `G4`，再然后 `C5`。
3. 在最后一个音符后面写 `off`，让它停下来。
4. 勾选 **循环**，按 **播放**。按 **Esc** 停止。
5. 在声部 1 上加一条低音（第 1 步写 `C3`，第 5 步写 `G2`）。对声部 0 使用 **静音**，就能只听低音。

AudioStudio 会自动保存。**代码里的样子** 卡片显示你的积木将要变成的 C 语句。

## 4. 在游戏中使用它们

回到积木编辑器，打开 **声音** 分类：

- 把 **播放配乐 Theme** 放进 *当游戏开始时*；
- 把 **播放音效 Catch** 放在玩家接到东西的地方。

按 **运行**（Shift+F10）：你会听到和 AudioStudio 中一样的声音。看看生成的 C：
`prg32_audio_play_track(0);` 和 `prg32_audio_note(7, 8, 76, 255, 120);`。你能说出每个数字的意思吗？
（提示：声部、乐器、音符、音量、毫秒。）

## 5. 课堂讨论的问题

- 为什么音效有自己的声部？如果音乐也用那个声部会怎么样？
- 把配乐的速度从 120 改成 180。生成的 C 中什么变了，什么没变？
- 给音效改个名字。代码生成器会说什么？为什么它不去猜？
