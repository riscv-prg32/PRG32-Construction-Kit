# Tutorial 3: Draw and Convert a Sprite

Goal: create a sprite and convert it to a C array.

## 1. Open Sprite Lab

Open your project in the IDE and click **Sprite Lab** in the top menu (or **Sprites** in the
project files). On the Projects page, the **Sprite Lab** button of a project card does the same.

## 2. Create a new sprite

1. Click **New**.
2. Name it `player`.
3. Use 16 by 16 pixels.
4. Pick a paint color.
5. Draw a simple character.

## 3. Save

Click **Save**. The sprite is kept with your project (as JSON on the server, or in this browser
without an account).

## 4. Convert to C

Click **Convert to C**. The C panel shows a `uint16_t` RGB565 array.

## 5. Find the artifact

Open the menu with your name (top right) and choose **Artifacts**. Download the generated sprite C file.
