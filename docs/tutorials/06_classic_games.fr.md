# Leçon 6 : jeux classiques

Objectif : étudier, jouer et modifier des jeux complets faits uniquement de blocs.

1. Sur la page Projets, clique sur **Exemples** et ajoute un jeu marqué **jeu complet**.
2. Ouvre sa leçon : [games/README.md](games/README.md) liste Pong, Breakout,
   Space Invaders, Asteroids et Snake.
3. Présente-le en classe : ouvre `/docs/presentations/<game>.html` et utilise les
   flèches (`F` pour le plein écran). Imprime en PDF pour les documents.
4. Suis les étapes : chacune montre les blocs exacts du jeu et le C qu'ils
   deviennent.
5. Termine avec **Compiler**, télécharge la cartouche depuis l'onglet **Compilation** et lance-la
   sur la carte PRG32, dans QEMU ou dans PRG32-QT.
