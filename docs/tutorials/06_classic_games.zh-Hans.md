# 第 6 课：经典游戏

目标：研究、玩并修改只用积木做成的完整游戏。

1. 在“项目”页面点击 **示例**，添加一个标记为 **完整游戏** 的游戏。
2. 打开它的课程：[games/README.md](games/README.md) 列出了 Pong、Breakout、
   Space Invaders、Asteroids 和 Snake。
3. 在课堂上展示：打开 `/docs/presentations/<game>.html`，用方向键翻页（按 `F` 全屏）。
   可以打印成 PDF 作为讲义。
4. 按步骤进行：每一步都显示游戏中确切的积木，以及它们变成的 C 代码。
5. 最后点击 **编译**，从 **构建** 标签页下载卡带，在 PRG32 电路板、QEMU 或 PRG32-QT 上运行它。
