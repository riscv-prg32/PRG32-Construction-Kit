# 第 2 课：接东西的游戏

目标：让玩家左右移动，并让它留在屏幕里。

## 1. 从第 1 课开始

打开你的项目，或者新建一个项目。

## 2. 加上移动

在 `每帧更新` 中加上：

```text
如果按住按钮 左
  把 player_x 增加 -3

如果按住按钮 右
  把 player_x 增加 3

让 player_x 保持在 0 和 304 之间
```

## 3. 测试移动

1. 点击 **运行**（Shift+F10），然后点击游戏屏幕。
2. 使用左右方向键。
3. 检查方块不能离开屏幕。

## 4. 看看 C 代码

点击 **生成**，找到：

```c
uint32_t input = prg32_input_read();
if (input & PRG32_BTN_LEFT) {
    player_x += -3;
}
```

讨论一下：为什么积木说的是“按钮”，而 C 代码用的是位掩码？
