# Schnellstart (Deutsch)

Andere Sprachen: [English](quickstart.en.md) · [Italiano](quickstart.it.md) ·
[Español](quickstart.es.md) · [Français](quickstart.fr.md) · [简体中文](quickstart.zh-Hans.md)

1. **Öffne das Kit** in einem Browser. Wähle deine Sprache im Menü oben
   (English, Italiano, Español, Français, Deutsch, 简体中文).
2. **Kein Konto?** Drücke *Ohne Konto ausprobieren*: Deine Spiele bleiben nur in diesem Browser.
3. **Neues Projekt.** Wähle, wie du es schreibst: **Blöcke**, **C**, **Assembly (RISC-V)** oder
   **Python (PRG32 Python)**. Gib ihm einen Titel und drücke *Erstellen*.
4. **Ausführen** (Umschalt+F10) baut das Spiel und startet es im Simulator rechts. Klicke auf den
   Bildschirm und benutze die Pfeiltasten (A und B sind Z und X).
5. **Erzeugen** (Strg+Umschalt+G) zeigt das C und das RISC-V-Assembly, das das Kit erzeugt,
   Zeile für Zeile erklärt. Es ist in jeder Sprache der Oberfläche gleich (die Code-Kommentare
   sind auf Englisch).
6. **Kompilieren** (Strg+Umschalt+B, braucht ein Konto) erstellt die `.prg32`-Cartridge zum
   Herunterladen, für eine PRG32-Konsole oder PRG32-QT.
7. **Debuggen**: Öffne den Tab *Debuggen*, drücke eine Zeilennummer, um dort anzuhalten, dann
   *Nächste Zeile*.
8. **Deine Daten**: Der Link unten *Datenschutz und deine Daten* sagt, was das Kit speichert und
   warum.

Lehrkräfte: Die Tutorials in [docs/tutorials](.) (auf Englisch) gehen weiter: Fangspiel,
Sprites, Klang, Veröffentlichen, Debugger, PRG32 Python.
