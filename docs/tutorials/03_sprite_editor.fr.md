# Leçon 3 : dessine et convertis un sprite

Objectif : créer un sprite et le convertir en tableau C.

## 1. Ouvre Sprite Lab

Ouvre ton projet dans l'IDE et clique sur **Sprite Lab** dans le menu du haut (ou sur
**Sprites** dans les fichiers du projet). Sur la page Projets, le bouton **Sprite Lab** de la
carte d'un projet fait la même chose.

## 2. Crée un nouveau sprite

1. Clique sur **Nouveau**.
2. Appelle-le `player`.
3. Utilise 16 sur 16 pixels.
4. Choisis une couleur de peinture.
5. Dessine un personnage simple.

## 3. Enregistre

Clique sur **Enregistrer**. Le sprite est gardé avec ton projet (en JSON sur le serveur, ou
dans ce navigateur sans compte).

## 4. Convertis en C

Clique sur **Convertir en C**. Le panneau C montre un tableau RGB565 de `uint16_t`.

## 5. Trouve l'artefact

Ouvre **Artefacts**. Télécharge le fichier C généré du sprite.
