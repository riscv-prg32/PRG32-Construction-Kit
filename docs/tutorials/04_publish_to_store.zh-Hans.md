# 第 4 课：准备并发布卡带包

目标：从一个积木项目制作 Cartridge Store 的包。

## 1. 生成

打开一个项目，点击 **生成**。确认生成的 C 看起来合理。

## 2. 准备卡带

点击 **编译**。

如果安装了 PRG32 构建工具链，结果会是一个可以发布的包，里面有 `.prg32` 文件。如果没有安装，本工具会创建一个只有源代码的教学包；Docker 镜像已经内置了工具链（参见 `../install_cartridge_build.md`）。

发布之前想先试一个卡带，可以按 **运行**（右边的模拟器），或者从 **构建** 标签页下载一个。
请发布由 **编译** 生成的包，这样商店就能得到所有架构。

## 3. 配置商店配置

1. 打开 **发布**。
2. 添加一个带 Cartridge Store 地址的配置。
3. 如果你的商店需要，再添加一个 Bearer 令牌。

## 4. 发布

1. 在列表中找到这个包。
2. 点击 **检查**：页面会准确显示将要发送的内容（商店、卡带、版本、文件指纹）。
3. 勾选复选框，点击 **确认**，然后阅读结果面板。

发布需要“发布者”角色；没有这个角色时，请老师替你发布。

真正的 Cartridge Store 可能会返回一个待审核的提交，需要由编辑审核。
