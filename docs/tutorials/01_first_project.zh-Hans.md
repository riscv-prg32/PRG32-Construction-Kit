# 第 1 课：第一个积木项目

目标：做一个小小的 PRG32 游戏，画出一个代表玩家的方块。

## 1. 创建项目

1. 打开首页。
2. 点击 **新建项目**。
3. 保持选中 **积木**。（对话框里还有 **C**、**汇编（RISC-V）** 和 **Python（PRG32 Python）**：
   它们从一个已经能运行的小游戏开始，写成代码并逐行解释。）
4. 把标题设为 `First Square`。
5. 点击 **创建**。

## 2. 设置初始状态

在积木区中：

1. 拖入 `当游戏开始时`。
2. 加上 `把 player_x 设为 150`。
3. 加上 `把 player_y 设为 180`。

## 3. 画出方块

1. 拖入 `每帧绘制`。
2. 加上 `清空屏幕 黑色`。
3. 加上 `画矩形 x player_x y player_y 宽 16 高 16 颜色 黄色`。

## 4. 运行它

点击 **运行**（Shift+F10）。本工具会构建你的游戏，并在右边的模拟器中启动它：你应该会在
PRG32 屏幕上看到一个黄色方块。

## 5. 保存和导出

1. 点击 **保存**（Ctrl+S）。
2. 打开 **项目** 菜单，选择 **导出为 JSON**。

下载的文件是一个以 JSON 保存的 PRG32 积木游戏。

## 6. 为你的 PRG32 制作卡带

点击 **编译**（需要账户），然后点击 **构建** 标签页中的 **下载 esp32c6 .prg32** 链接。本工具
会编译你的积木，浏览器会保存一个类似 `first-square-esp32c6.prg32` 的文件。这个文件就是你的
PRG32 卡带：把它复制到电路板的卡带槽中。旁边的 **下载 qemu .prg32** 链接是同一个游戏，用于
QEMU 模拟器。
