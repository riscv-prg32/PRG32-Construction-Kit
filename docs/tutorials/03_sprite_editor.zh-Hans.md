# 第 3 课：画一个精灵并转换它

目标：创建一个精灵，并把它转换成 C 数组。

## 1. 打开 Sprite Lab

在 IDE 中打开你的项目，点击顶部菜单中的 **Sprite Lab**（或者项目文件中的 **精灵**）。在“项目”
页面上，项目卡片上的 **Sprite Lab** 按钮也能做同样的事。

## 2. 新建一个精灵

1. 点击 **新建**。
2. 把它命名为 `player`。
3. 使用 16 × 16 像素。
4. 选一种画笔颜色。
5. 画一个简单的角色。

## 3. 保存

点击 **保存**。精灵会和你的项目一起保存（在服务器上以 JSON 保存；没有账户时保存在这个浏览器里）。

## 4. 转换为 C

点击 **转换为 C**。C 面板会显示一个 `uint16_t` 类型的 RGB565 数组。

## 5. 找到制品

打开 **制品**。下载生成的精灵 C 文件。
