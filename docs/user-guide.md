# User guide (students and teachers)

Start here, then follow the links.

1. **First game:** `tutorials/01_first_project.md`, then
   `tutorials/02_catch_game.md`.
2. **Classic games with slide decks:** `tutorials/games/README.md`.
3. **Sprites:** `tutorials/03_sprite_editor.md`.
4. **Reading the C and assembly the blocks make:** `generated_code.md`.
5. **Saving, handing in and sharing projects:** `project_archive.md`;
   going back to an earlier version or a deleted project: `project_history.md`.
6. **Writing a game directly in RISC-V assembly:** `handwritten_assembly.md`.
7. **Playing your real cartridge in the browser:** `wasm_runtime.md`;
   stepping through it instruction by instruction: `tutorials/07_debugger.md`.
   Working without the server: `offline.md`.
   The IDE (files, tabs, keyboard shortcuts): `ide.md`.
   Sound effects and music for your game: `audio_studio.md`, `tutorials/08_audio_studio.md`.
8. **Publishing to a Cartridge Store:** `tutorials/04_publish_to_store.md`.
9. **Running a lab (teachers):** `tutorials/05_teacher_lab.md`.
