# Executive summary

Audit date: 2026-10-19 (Europe/Rome)

Audited revision: `ide/refine-after-731e378` at `5dd98a95a0f910091896eb1149d29a5f96265b3d`

Recommendation: **NO-GO for the complete Full IDE scope; technically CONDITIONAL for a bounded classroom preview**

Refinement phases 3–4 materially close the previous IDE language-service and mandatory debugger blockers. The C and assembly services are browser-only, deterministic, offline, generated from pinned SDK/ABI and validator inputs, and tested against unsafe/generated corpora. Source and block debugging now provides deterministic block→IR→source→address maps, source/block/conditional breakpoints, active-block highlighting, DWARF locals/globals/call stack/watches, CSR and stack views, compressed-instruction correctness, and safe address-only fallback.

The critical safety invariants are implemented and exercised: source-map markers leave generated code byte-identical; debug builds only add approved flags; a debug ELF is accepted only when its loadable image equals the PRG32 cartridge; the ELF is never served; debug artifacts are owner-scoped; paths are stripped; damaged/missing data falls back safely. All 65 required Chrome tests passed, including scenario D and accessibility/CSP checks. Store-egress tests passed 94/94, and 37 feasible SDK/WASM/native tests passed.

The complete Full IDE remains NO-GO because approved scope still lacks guest policies/IndexedDB, academic OIDC with PKCE and scoped student/TA/teacher roles, Drive/OneDrive, shared live Store conformance, and verified hardware/iOS delivery. These are product-scope and external-validation gaps rather than a newly demonstrated critical exploit. A tightly labeled classroom preview may be conditional if deployments use local accounts, exclude guest/cloud/device claims, retain the production sandbox, and document the limitations.

## Limitations

Committed debug fixtures were generated by a recorded real toolchain, but their regeneration was skipped locally because that toolchain is absent. CI/container results in project documentation were inspected, not independently executed.
