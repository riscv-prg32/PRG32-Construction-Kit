A PRG32 game has 8 voices. In a soundtrack, voice 0 plays instrument 0, voice 1 instrument 1, and so on.

A sound effect is one note with its own instrument. The Blocks "play sound effect" block plays it by name.

A soundtrack is a grid: one row per voice, one column per step. Type a note (C4, F#5 or a number 0–127), off to end a note, or leave it empty. Arrow keys move around the grid.
